# 🐰 小动物数数乐园 - 游戏说明

## 游戏特点

### 🎯 学习目标
- 教 4 岁小孩理解加法的基本原理
- 通过直观的动物数数培养数感
- 1-10 以内的加法练习

### 🎨 游戏玩法

1. **看题目**：屏幕上会显示两组可爱的小动物
2. **数一数**：孩子可以数出每组动物的数量
3. **做加法**：把两组的数量相加
4. **选答案**：从 3 个选项中选择正确答案

### ✨ 有趣元素

**5 种动物动画效果**：
- 🐰 跳跃 (bounce) - 上下跳动
- 🐱 摇摆 (wiggle) - 左右摇摆
- 🐶 弹跳 (hop) - 大幅弹跳
- 🐸 旋转 (spin) - 360 度旋转
- 🐻 摆动 (swing) - 像秋千一样摆动

**每只小动物都会随机选择一种动画效果，让画面更生动有趣！**

### 🏆 游戏机制

- 每次游戏共 **5 道随机题目**
- 答对得 **10 分**，答错不扣分
- 答对时有 **彩带庆祝特效**
- 答错时会显示正确答案，帮助孩子学习
- 5 题结束后显示总分，可以 **再玩一次**

### 📊 题目范围

- 每组动物数量：1-5 只
- 加法结果：2-10
- 每次题目随机，不会重复

## 使用说明

直接用浏览器打开 `counting-game.html` 文件即可开始游戏！

适合 4-6 岁儿童，建议家长陪同一起玩耍。
